# 社交任务模块

## 概述
社交任务模块是FreshBox系统中的一个核心功能，旨在通过社交化任务鼓励用户积极参与临期食品的再利用，减少食物浪费，并建立社区互动。

## 功能特点

### 多样化任务类型
- **创意料理挑战**：使用盲盒食材创作料理并分享
- **食物拯救行动**：收集并分享减少食物浪费的实用技巧
- **社区分享会**：组织临期食品分享活动并记录过程
- **零浪费挑战**：实践零浪费烹饪并分享经验
- **教育科普任务**：制作关于食品安全和保鲜的科普内容

### 任务生命周期
- 任务创建
- 任务进行（多阶段里程碑）
- 任务完成与奖励
- 社区互动与评论

## 技术实现

### 后端API
- `GET /api/v1/tasks`：获取任务列表
- `GET /api/v1/tasks/:id`：获取任务详情
- `GET /api/v1/tasks/:id/progress`：获取任务进度
- `POST /api/v1/tasks`：创建新任务(需认证)
- `PUT /api/v1/tasks/:id/status`：更新任务状态(需认证)
- `POST /api/v1/tasks/:id/content`：上传任务内容(需认证)
- `GET /api/v1/tasks/recommended`：获取推荐任务
- `GET /api/v1/tasks/popular`：获取热门任务
- `GET /api/v1/tasks/:id/contents`：获取任务内容列表

### 前端页面
- `/boxes/tasks`：任务列表页面
- `/boxes/tasks/:id`：任务详情页面
- `/boxes/tasks/create`：创建任务页面

### 数据模型
- `Task`：任务基本信息
- `TaskProgress`：任务进度信息
- `TaskContent`：任务提交内容
- `TaskComment`：任务评论

## 集成点
- 与盲盒系统的集成：通过盲盒购买触发任务、使用盲盒完成任务
- 与积分系统的集成：完成任务获得积分奖励
- 与社区系统的集成：任务成果在社区中展示和分享
